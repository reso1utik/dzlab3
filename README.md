## Условие задачи

Написать и отладить программу расчета площади и объема
тетраэдра с длиной ребра l (где l – задаются пользователем)

## 1. Алгоритм и блок-схема
### Алгоритм решения
1. **Начало**
2. Задать исходные данные: 
   - l (Длина ребра)
3. Выполнить сравнение:
   - l > 0 то продолжить выполнение программы
   - l < или = 0 то вывести ошибку и завершить программу
4. Вычислить значение площади и объема тетраэдра 
   - s = (sqrt(3)) * l^2
   - v = ((sqrt(2)) / 12) * l^3
5. Вывести результаты  
6. **Конец**
